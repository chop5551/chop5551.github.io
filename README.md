# Для тебя 💖

Личная страничка на GitHub Pages: https://chop5551.github.io

## Как добавить картинки

- **Фото** — положи `N.webp` в `img/` и поменяй `range(40)` в `CONFIG.photos` в `index.html`.
- **Календарь** — положи файл в `calendar/` (например `среда_5.webp`) и допиши имя в `CONFIG.calendar`.
- **Сюрпризы** — `gusto/N.webp`, число в `CONFIG.surprises`.

Картинки лучше загружать в формате WebP (до ~1080px по длинной стороне) — так страница открывается мгновенно.
После изменения списка файлов увеличь `VERSION` в `sw.js`, чтобы обновился офлайн-кэш.

## Десерты-сюрпризы

Кнопка «Сюрприз» показывает случайный десерт из актуального меню https://gustobakery.ru/deserty:
фото, название, вес, цену, описание и ссылку.

- Список лежит в `gusto/desserts.json`. Обновить его (раз в пару недель или когда меню поменяется):
  1. Открой https://gustobakery.ru/deserty в своём браузере на компьютере.
  2. Нажми F12 → вкладка **Console**, вставь код из `scripts/desserts-from-browser.js`, нажми Enter
     (если Chrome попросит, сначала напечатай `allow pasting`).
  3. JSON уже скопирован. Открой `gusto/desserts.json` на GitHub (или создай файл) → ✏️ → вставь → **Commit changes**.
- Автоматически по расписанию не собирается: сайт кондитерской показывает серверам GitHub капчу,
  а из браузера на github.io его прочитать нельзя (CORS).
- Если списка нет или картинка не загрузилась, показываются локальные картинки из `gusto/*.webp`.
